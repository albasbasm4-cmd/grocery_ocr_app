# ترتيب تشغيل ملفات الترحيل الجديدة (المرحلة A)

يجب تشغيل ملفات الترحيل الجديدة في محرر SQL في Supabase بالترتيب الدقيق التالي:

1. `20261111000017_a_schema_tables.sql` - إضافة حقول الصلاحيات وجدول رموز الانضمام وطلبات الانضمام وسجل التدقيق ورموز PIN
2. `20261111000017_b_security_helpers.sql` - دوال المساعدة للتحقق من الصلاحيات والبيع وتوحيد وحدات المنتجات
3. `20261111000017_c_triggers_and_product_update.sql` - تريجرات حماية المالك ومنع تعديل cost_price للموظفين ودالة تعديل الحقول الحساسة
4. `20261111000017_d_rls_policies.sql` - سياسات RLS للمنتجات والتصنيفات وطلبات الانضمام وسجل التدقيق
5. `20261111000017_e_process_sale.sql` - دالة إتمام البيع مع التحقق من صلاحية can_sell للموظف
6. `20261111000017_f_adjust_stock.sql` - دالة تسوية المخزون للمالك أو موظف write دون طلب PIN للمالك
7. `20261111000017_g_void_and_return_sales.sql` - دوال إلغاء الفاتورة وإرجاع العناصر للمالك دون طلب PIN
8. `20261111000017_h_bulk_upsert_products.sql` - دالة الاستيراد الجماعي للمنتجات لمالك المتجر دون طلب PIN
9. `20261111000017_i_backup_export.sql` - دالة تصدير النسخة الاحتياطية الكاملة لمالك المتجر
10. `20261111000017_j_request_and_cancel_join.sql` - دوال تقديم طلب انضمام بالرمز وإلغاء الطلب المعلق للمستخدم
11. `20261111000017_k_approve_and_reject_join.sql` - دوال قبول طلب الانضمام (بجلسة PIN) ورفضه (دون PIN)
12. `20261111000017_l_store_join_queries.sql` - دوال استعلام المالك عن طلبات الانضمام وعدادها وطلبات المستخدم المعلقة
13. `20261111000017_m_staff_permissions_and_status.sql` - دوال تعديل صلاحيات الموظف وتعطيله وحذفه (تتطلب جلسة PIN للمدير)
14. `20261111000017_n_leave_and_list_stores.sql` - دوال مغادرة الموظف للمتجر وسرد متاجر المستخدم مع أدواره وصلاحياته
15. `20261111000017_o_join_code_and_audit_log.sql` - دوال إعادة توليد رمز الانضمام وسجل تدقيق العمليات الحساسة وتغيير PIN
16. `20261111000017_p_pin_reset_code_rpc.sql` - دالة استعادة وتعيين رمز PIN الجديد عبر رمز التحقق المكون من 6 أرقام
